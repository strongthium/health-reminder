# The health-reminder manual

Every window of the program, with what each part of it does and how to use it.

## The short version

```
1. Download health-reminder.exe (Releases, or public\ in the source) and run it. Nothing to install.
2. Click Add reminder, pick what it is, type the DIN or NDC from the label (or the name) and click Search.
3. Pick the product and the strength, set the times and the amount at each, and click Save.
4. Close the window and keep it running in the tray: when something is due, it rings until it's answered.
```
